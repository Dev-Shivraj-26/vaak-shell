## 📌 परिचय (Introduction)

**वाक्-शेल (Vaak-Shell)** का उद्देश्य टर्मिनल और कंप्यूटिंग को आम जनमानस और नए विद्यार्थियों के लिए अत्यंत सरल बनाना है[span_1](start_span)[span_1](end_span)। 

अक्सर नए उपयोगकर्ता लिनक्स के संक्षिप्त अंग्रेज़ी कमांड्स जैसे `ls`, `pwd`, `mkdir`, `chmod` देखकर भ्रमित हो जाते हैं[span_2](start_span)[span_2](end_span)। वाक्-शेल दैनिक जीवन की व्यावहारिक **हिंदुस्तानी (हिंदी-उर्दू-अंग्रेज़ी मिश्रित)** शब्दावली को एक संप्रभु शेल लेयर के रूप में जोड़ता है, जिससे कोई भी व्यक्ति बिना किसी पूर्व तकनीकी अनुभव के सीधे स्वाभाविक शब्दों में टर्मिनल नियंत्रित कर सकता है[span_3](start_span)[span_3](end_span)।

## 🚀 संस्थापन विधियाँ (Installation Methods)

आप नीचे दी गई दोनों में से किसी भी एक विधि का उपयोग करके इसे तुरंत स्थापित कर सकते हैं[span_4](start_span)[span_4](end_span):

### विधि १: एक-क्लिक स्वचालित संस्थापन (अनुशंसित)
टर्मिनल में यह कमांड चलाएँ[span_5](start_span)[span_5](end_span):

```bash
curl -fsSL https://raw.githubusercontent.com/Dev-Shivraj-26/vaak-shell/main/install.sh
```
```
https://raw.githubusercontent.com/Dev-Shivraj-26/vaak-shell/main/install.sh | bash
```
विधि २: गिट क्लोन द्वारा संस्थापन (वैकल्पिक / Fallback)
यदि curl में कोई समस्या आए या आप स्रोत कोड देखना चाहें:
```
git clone https://github.com/Dev-Shivraj-26/vaak-shell.git
```
https://github.com/Dev-Shivraj-26/vaak-shell.git
```
cd vaak-shell
bash install.sh
```
⚙️ सक्रियण एवं उपयोग (Activation)
संस्थापन पूरा होने के बाद परिवर्तनों को तुरंत लागू करने हेतु यह चलाएँ:
```
source ~/.bashrc
```
सभी उपलब्ध कमांड्स की सूची देखने के लिए टर्मिनल में सीधे टाइप करें:

📖 संपूर्ण कमांड मार्गदर्शिका (Command Reference Table)
नए उपयोगकर्ताओं की सुविधा के लिए सभी कमांड्स को उनके कार्य, हिंदुस्तानी शब्द और मूल लिनक्स समकक्ष के साथ वर्गीकृत किया गया है:
१. संचिका एवं संदर्शिका प्रबंधन (Files & Folders)
| क्या कार्य करना है? (कार्य विवरण) | हिंदुस्तानी कमांड (वाक्-शेल) | मूल लिनक्स कमांड (English) |
|---|---|---|
| वर्तमान फ़ोल्डर में मौजूद फ़ाइलों की सूची देखना | सूची | ls --color=auto |
| फ़ाइलों की विस्तृत जानकारी (आकार, अनुमति आदि) देखना | सूची_विस्तार | ls -lah |
| आप अभी किस फ़ोल्डर में हैं (वर्तमान पथ) देखना | वर्तमान | pwd |
| किसी फ़ोल्डर के अंदर जाना (और उसकी फ़ाइलें देखना) | जाओ <फ़ोल्डर_नाम> | cd <folder> && ls |
| पिछले फ़ोल्डर में बाहर लौटना | पीछे | cd .. |
| किसी फ़ाइल के अंदर का पाठ (Text) पढ़ना | पढ़ो <फ़ाइल_नाम> | cat <file> |
| फ़ाइल की शुरुआती २० पंक्तियाँ पढ़ना | शीर्ष <फ़ाइल_नाम> | head -n 20 |
| फ़ाइल की अंतिम २० पंक्तियाँ पढ़ना | अंत <फ़ाइल_नाम> | tail -n 20 |
| नया फ़ोल्डर बनाना | बनाओ <फ़ोल्डर_नाम> | mkdir -p |
| फ़ाइल या फ़ोल्डर हटाना (सुरक्षित पुष्टि सहित) | हटाओ <नाम> | rm -ri |
| बिना पूछे तुरंत जबरन हटाना | बलपूर्वक_हटाओ <नाम> | rm -rf |
| फ़ाइल या फ़ोल्डर की प्रतिलिपि (कॉपी) बनाना | प्रतिलिपि <स्रोत> <लक्ष्य> | cp -r |
| फ़ाइल का नाम बदलना या स्थानांतरित (मूव) करना | बदलो <पुराना_नाम> <नया_नाम> | mv |
| नाम से किसी फ़ाइल को ढूँढना | खोजो_फ़ाइल <नाम> | find . -name |
| फ़ाइलों के अंदर किसी शब्द को ढूँढना | खोजो_शब्द <शब्द> | grep -rnw . -e |
| टर्मिनल से बाहर निकलना / बंद करना | बाहर / बंद | exit |
💡 विशेष स्मार्ट कमांड: मिटाओ
वाक्-शेल में मिटाओ एक संदर्भ-संवेदनशील (Context-Aware) स्मार्ट कमांड है:
 * केवल मिटाओ लिखने पर: यह टर्मिनल स्क्रीन को साफ़ (clear) कर देता है।
 * मिटाओ <फ़ाइल> लिखने पर: यह उस फ़ाइल को हटाने (rm -ri) की सुरक्षित पुष्टि प्रक्रिया चलाता है।
२. सिस्टम, नेटवर्क एवं संसाधन प्रबंधन (System & Network)
| क्या कार्य करना है? (कार्य विवरण) | हिंदुस्तानी कमांड (वाक्-शेल) | मूल लिनक्स कमांड (English) |
|---|---|---|
| स्क्रीन को पूरी तरह साफ़ करना | साफ़ | clear |
| रैम (RAM) मेमोरी की स्थिति जाँचना | स्मृति | free -h |
| स्टोरेज (डिस्क स्पेस) की स्थिति देखना | डिस्क_स्थान | df -h |
| वर्तमान फ़ोल्डरों द्वारा घेरा गया स्पेस देखना | फ़ोल्डर_भार | du -sh * |
| सिस्टम में चल रहे सभी प्रोग्राम्स देखना | प्रक्रियाएँ | ps aux |
| किसी अटके हुए प्रोग्राम को बंद करना | मारो <PID> | kill -9 |
| इंटरनेट से सीधे कोई फ़ाइल डाउनलोड करना | डाउनलोड <URL> | curl -O -L |
| अलग नाम देकर फ़ाइल डाउनलोड करना | डाउनलोड_नाम <नाम> <URL> | curl -L -o |
| इंटरनेट कनेक्टिविटी का परीक्षण करना | जाल_जाँच | ping -c 4 8.8.8.8 |
| अपना सार्वजनिक आईपी (IP) पता देखना | मेरा_आईपी | curl -s ifconfig.me |
३. पैकेज प्रबंधन (Package Management)
| क्या कार्य करना है? (कार्य विवरण) | हिंदुस्तानी कमांड (वाक्-शेल) | मूल लिनक्स कमांड (English) |
|---|---|---|
| सिस्टम के सभी पैकेजों को अद्यतित (Update) करना | अद्यतन | pkg update && pkg upgrade -y |
| कोई नया टूल या पैकेज इंस्टॉल करना | स्थापित_करो <पैकेज> | pkg install -y |
| किसी इंस्टॉल किए गए पैकेज को हटाना | निष्कासित_करो <पैकेज> | pkg uninstall -y |

📖 संपूर्ण कमांड मार्गदर्शिका (Command Reference Table)
नए उपयोगकर्ताओं की सुविधा के लिए सभी कमांड्स को उनके कार्य, हिंदुस्तानी शब्द और मूल लिनक्स समकक्ष के साथ वर्गीकृत किया गया है:
१. संचिका एवं संदर्शिका प्रबंधन (Files & Folders)
| क्या कार्य करना है? (कार्य विवरण) | हिंदुस्तानी कमांड (वाक्-शेल) | मूल लिनक्स कमांड (English) |
|---|---|---|
| वर्तमान फ़ोल्डर में मौजूद फ़ाइलों की सूची देखना | सूची | ls --color=auto |
| फ़ाइलों की विस्तृत जानकारी (आकार, अनुमति आदि) देखना | सूची_विस्तार | ls -lah |
| आप अभी किस फ़ोल्डर में हैं (वर्तमान पथ) देखना | वर्तमान | pwd |
| किसी फ़ोल्डर के अंदर जाना (और उसकी फ़ाइलें देखना) | जाओ <फ़ोल्डर_नाम> | cd <folder> && ls |
| पिछले फ़ोल्डर में बाहर लौटना | पीछे | cd .. |
| किसी फ़ाइल के अंदर का टेक्स्ट/पाठ पढ़ना | पढ़ो <फ़ाइल_नाम> | cat <file> |
| फ़ाइल की शुरुआती २० पंक्तियाँ पढ़ना | शीर्ष <फ़ाइल_नाम> | head -n 20 |
| फ़ाइल की अंतिम २० पंक्तियाँ पढ़ना | अंत <फ़ाइल_नाम> | tail -n 20 |
| नया फ़ोल्डर बनाना | बनाओ <फ़ोल्डर_नाम> | mkdir -p |
| फ़ाइल या फ़ोल्डर हटाना (सुरक्षित पुष्टि सहित) | हटाओ <नाम> | rm -ri |
| बिना पूछे तुरंत जबरन हटाना | बलपूर्वक_हटाओ <नाम> | rm -rf |
| फ़ाइल या फ़ोल्डर की प्रतिलिपि (कॉपी) बनाना | प्रतिलिपि <स्रोत> <लक्ष्य> | cp -r |
| फ़ाइल का नाम बदलना या स्थानांतरित (मूव) करना | बदलो <पुराना_नाम> <नया_नाम> | mv |
| नाम से किसी फ़ाइल को ढूँढना | खोजो_फ़ाइल <नाम> | find . -name |
| फ़ाइलों के अंदर किसी शब्द को ढूँढना | खोजो_शब्द <शब्द> | grep -rnw . -e |
२. सिस्टम, नेटवर्क एवं संसाधन प्रबंधन (System & Network)
| क्या कार्य करना है? (कार्य विवरण) | हिंदुस्तानी कमांड (वाक्-शेल) | मूल लिनक्स कमांड (English) |
|---|---|---|
| स्क्रीन को पूरी तरह साफ़ करना | साफ़ | clear |
| रैम (RAM) मेमोरी की स्थिति जाँचना | स्मृति | free -h |
| स्टोरेज (डिस्क स्पेस) की स्थिति देखना | डिस्क_स्थान | df -h |
| वर्तमान फ़ोल्डरों द्वारा घेरा गया स्पेस देखना | फ़ोल्डर_भार | du -sh * |
| सिस्टम में चल रहे सभी प्रोग्राम्स देखना | प्रक्रियाएँ | ps aux |
| किसी अटके हुए प्रोग्राम को बंद करना | मारो <PID> | kill -9 |
| इंटरनेट से सीधे कोई फ़ाइल डाउनलोड करना | डाउनलोड <URL> | curl -O -L |
| अलग नाम देकर फ़ाइल डाउनलोड करना | डाउनलोड_नाम <नाम> <URL> | curl -L -o |
| इंटरनेट कनेक्टिविटी का परीक्षण करना | जाल_जाँच | ping -c 4 8.8.8.8 |
| अपना सार्वजनिक आईपी (IP) पता देखना | मेरा_आईपी | curl -s ifconfig.me |
३. पैकेज प्रबंधन (Package Management - Termux)
| क्या कार्य करना है? (कार्य विवरण) | हिंदुस्तानी कमांड (वाक्-शेल) | मूल लिनक्स कमांड (English) |
|---|---|---|
| सिस्टम के सभी पैकेजों को अद्यतित (Update) करना | अद्यतन | pkg update && pkg upgrade -y |
| कोई नया टूल या पैकेज इंस्टॉल करना | स्थापित_करो <पैकेज> | pkg install -y |
| किसी इंस्टॉल किए गए पैकेज को हटाना | निष्कासित_करो <पैकेज> | pkg uninstall -y |
| किसी नए पैकेज को खोजना | ढूँढो_पैकेज <नाम> | pkg search |
४. गिट संस्करण नियंत्रण (Git Sovereign Stack)
| क्या कार्य करना है? (कार्य विवरण) | हिंदुस्तानी कमांड (वाक्-शेल) | मूल गिट कमांड (English) |
|---|---|---|
| नया गिट प्रोजेक्ट आरंभ करना | गिट_आरंभ | git init |
| गिटहब से प्रोजेक्ट डाउनलोड (क्लोन) करना | गिट_क्लोन <URL> | git clone |
| गिट की वर्तमान स्थिति (Status) जाँचना | गिट_स्थिति | git status |
| सभी बदलावों को स्टेजिंग में जोड़ना | गिट_जोड़ो | git add . |
| संदेश के साथ बदलाव सुरक्षित (Commit) करना | गिट_प्रतिबद्ध "<संदेश>" | git commit -m |
| रिमोट सर्वर से ताज़ा कोड खींचना | गिट_खींचो | git pull |
| अपने बदलाव रिमोट सर्वर पर भेजना | गिट_भेजो | git push |
| प्रोजेक्ट का कमिट इतिहास देखना | गिट_इतिहास | git log --oneline --graph |
| शाखाओं (Branches) की सूची देखना | गिट_शाखा | git branch |
🛠️ निष्कासन (Uninstallation)
यदि आप वाक्-शेल को हटाकर अपने सिस्टम को पूर्ववत करना चाहते हैं:
| टर्मिनल से बाहर निकलना / बंद करना | `बाहर` / `बंद` | `exit` |
| बिना नाम दिए: स्क्रीन साफ़ करना / नाम देने पर: फ़ाइल हटाना | `मिटाओ [फ़ाइल_नाम]` | `clear` / `rm -ri` |

### 💡 विशेष स्मार्ट कमांड: `मिटाओ`
वाक्-शेल में `मिटाओ` एक संदर्भ-संवेदनशील (Context-Aware) स्मार्ट कमांड है:
* **केवल `मिटाओ` लिखने पर:** यह टर्मिनल स्क्रीन को साफ़ (`clear`) कर देता है।
* **`मिटाओ <फ़ाइल>` लिखने पर:** यह उस फ़ाइल को हटाने (`rm -ri`) की सुरक्षित पुष्टि प्रक्रिया चलाता है।


```
curl -fsSL https://raw.githubusercontent.com/Dev-Shivraj-26/vaak-shell/main/uninstall.sh
```
